Introduction, Problem & Motivation
Real-World Problem

The Global Waste Crisis

  • 2.01 Billion Tonnes of municipal solid waste generated annually.
  • Over 80% is dumped unsegregated into open landfills.
  • Contamination Bottleneck: When clean recyclables (paper, plastic) mix with wet food scraps, they become non-recyclable.

The Solution: Point-of-Disposal AI

  • Eliminates Manual Sorting: Protects sanitation workers from bio-aerosols, pathogens, and sharp glass/metal.
  • Instant Citizen Guidance: Replaces "wish-cycling" with immediate visual classification and bin directions.
  • Scalable Circular Economy: Maximizes purity of recycling streams right at the disposal container.
Simple Real-World Example: A student holding a used beverage cup or cardboard box is unsure which bin to use. Using our system's live camera, the item is classified in < 50ms, showing the exact bin color and whether to clean it first.

Main Project Objectives
Project Scope

1. Dataset Engineering

Curate 1,647 photographic samples across 5 balanced classes and apply aspect-ratio preserving crop to prevent item squashing.

2. Deep Learning Model

Fine-tune MobileNetV2 with depthwise separable convolutions to achieve ≥ 85% test accuracy and < 50ms inference.

3. Disposal Directives

Generate authoritative disposal instructions matched to the predicted class with designated municipal bin colors.

4. Empirical Dashboard

Build a live Chart.js statistics dashboard tracking real database records without hardcoded numbers.

5. Persistent History

Store record IDs, timestamps, confidence scores, and preview thumbnails in an SQLite relational database.

6. Safety & Awareness

Enforce a 60% confidence warning threshold and deploy a 5-module environmental awareness guide.

System Architecture
[1. INPUT] Camera Stream (WebRTC) OR Image File Upload (JPG/PNG/WEBP)
    ↓
[2. PREPROCESSING] RGB Standardization → ImageOps.fit(224, 224) → Normalize [-1, 1]
    ↓
[3. AI INFERENCE] MobileNetV2 (53 Layers + GAP + Dropout 0.3 + Dense 5 Softmax)
    ↓
[4. SAFETY LOGIC] Check Confidence Threshold (≥ 60% vs. < 60%)
    • If ≥ 60%: High Confidence Result + Standardized Disposal Directive + Bin Color
    • If < 60%: Amber Warning Alert ("AI not confident") + "Try Another Image"
    ↓
[5. PERSISTENCE] SQLite Database Archiving (Record ID, Class, Confidence, Thumbnail, Time)
    ↓
[6. TELEMETRY] Real-Time Waste Statistics Dashboard (Interactive Chart.js Visualizations)

Dataset & Preprocessing Pipeline
Data Engineering

Curated Dataset: 1,647 Images

  • Plastic (324) Water bottles, detergent jugs, food containers
  • Paper (318) Cardboard boxes, newspapers, packaging cartons
  • Metal (342) Soda cans, tin food cans, foil packaging
  • Glass (328) Clear & amber bottles, culinary jars, vials
  • Organic (335) Fruit peels, leftover food, tea grounds

Preprocessing Innovations

  • Aspect-Ratio Preserving Crop: Standard resizing squashes elongated bottles into squares. We use ImageOps.fit with bicubic interpolation to preserve natural silhouettes.
  • Mathematical Normalization: Scaled raw pixels [0, 255] to [-1.0, 1.0].
  • Data Augmentation: Random rotations (±20°), zoom, shifts, and horizontal flips during training to combat overfitting.
Data Split: 80% Training ($1,318$ images) • 20% Isolated Unseen Testing ($329$ images)

Methodology & AI Deep Learning Technique
AI Model Architecture

Why MobileNetV2?

  • Depthwise Separable Convolutions: Splits standard convolution into depthwise and pointwise operations, cutting computation by ~85%.
  • Inverted Residual Bottlenecks: Preserves complex gradient flow while maintaining lightweight memory footprint.
  • Compact File Size: Just 27.61 MB with 2.2 million parameters.
  • Sub-50ms Latency: Executes real-time inference on commodity CPUs and Raspberry Pi.

Custom Head & Two-Phase Training

  • Global Average Pooling: Reduces 7x7x1280 feature maps to a 1280 vector.
  • Dense + Dropout(0.3): Dense projection with regularization to prevent overfitting.
  • Softmax Output: Computes calibrated probabilities across all 5 waste classes.
  • Phase 1 (Transfer): 10 epochs with frozen base layers (η = 10-3).
  • Phase 2 (Fine-Tuning): 15 epochs unfreezing top 30 layers with cosine decay (η = 10-4).

System Features & Live Demonstration
Implemented System

1. Standardized Disposal Directives

Displays exact instructions matched to the predicted class (e.g., "Clean the item if possible and place it in the plastic recycling bin") with designated municipal bin badges.

2. Waste Statistics Dashboard

Live Chart.js bar and doughnut charts computing stream counts and percentage distributions strictly from actual SQLite database records (no fake data).

3. Classification History

Archives records newest-first with thumbnail previews, category pills, confidence scores, timestamps, and a modal-confirmed clear history function.

4. Low-Confidence Safety Warning

When confidence < 60%, displays an amber warning alert with a "Try Another Image" button, keeping predictions transparent.
